# Zaim API PoC スクリプト

設計検討メモ (`docs/zaim-auto-import-design.md`) の **Go/No-Go 判断** を行うための PoC スクリプトです。  
実アカウントで Zaim API から取得できるデータを確認し、自動取込の実装可否を判断します。

## 前提条件

- Python 3.10 以上
- Zaim アカウント
- Zaim Developers Center でのアプリケーション登録済み

## セットアップ

### 1. Zaim アプリケーション登録

1. <https://dev.zaim.net> にアクセスし、ログイン
2. 「新しいアプリケーションを追加」を選択
3. 以下を入力:
   - アプリケーション名: 任意（例: `house-expense-poc`）
   - アプリケーションの種類: **ブラウザアプリ**
   - サービスの URL: `http://127.0.0.1:5000/callback`
4. 発行された **コンシューマ ID** と **コンシューマシークレット** をメモ

### 2. Python 環境のセットアップ

```bash
cd scripts/zaim-poc
pip install -r requirements.txt
```

### 3. 環境変数の設定

```bash
cp .env.example .env
```

`.env` を編集し、コンシューマ情報を記入:

```env
ZAIM_CONSUMER_KEY="取得したコンシューマID"
ZAIM_CONSUMER_SECRET="取得したコンシューマシークレット"
```

## 使い方

### Step 1: アクセストークン取得

```bash
python zaim_poc.py authorize
```

1. 表示される URL をブラウザで開く
2. Zaim にログインして認可する
3. リダイレクト先 URL に含まれる `oauth_verifier` の値をコピーして入力
4. アクセストークンが自動的に `.env` に書き込まれる

### Step 2: データ取得 & Go/No-Go 判定

```bash
python zaim_poc.py fetch
```

以下のデータを取得して表示します:

1. **ユーザー認証確認** — OAuth が正しく動いているか
2. **口座一覧** — `account.id`, `account.name` など
3. **カテゴリ一覧** — `category.id`, `category.name` など
4. **ジャンル一覧** — `genre.id`, `genre.name` など
5. **明細 (money)** — 直近 60 日分（最大 100 件）

取得後、自動で以下の Go/No-Go チェックを実行します:

| チェック項目 | 重要度 | 判定基準 |
|---|---|---|
| 口座に一意な `id` が存在する | 🔴 必須 | `DataSource` との 1:1 マッピングに必要 |
| 口座に `name` が存在する | 🟡 推奨 | `DataSource.name` への対応 |
| 明細に一意な `id` が存在する | 🔴 必須 | 重複/更新検知に必要 |
| 明細に `date` が存在する | 🔴 必須 | `Transaction.usageDate` へのマッピング |
| 明細に `amount` / `price` が存在する | 🔴 必須 | `Transaction.amount` へのマッピング |
| 明細に `mode` が存在する | 🔴 必須 | `Transaction.type` へのマッピング |
| 明細に口座参照がある | 🟡 推奨 | `Transaction.dataSourceId` への紐付け |
| 明細に説明文系フィールドがある | 🟡 推奨 | `Transaction.description` へのマッピング |
| 明細にタイムスタンプがある | 🟢 任意 | 更新検知（なくても `hashKey` で代替可能） |
| 明細にカテゴリ情報がある | 🟢 任意 | カテゴリ自動マッピング |

### 判定結果

- **✅ Go** — 必要なフィールドがすべて確認できた → 実装に進める
- **⚠️ 条件付き Go** — 致命的ではないが一部不足 → 代替手段を検討して進める
- **❌ No-Go** — 必須フィールドが不足 → issue の方針を見直す
- **⚠️ 判定不可** — 明細が 0 件 → Zaim にデータを登録してから再実行

## 注意事項

- `.env` にはシークレットが含まれるため、**絶対にコミットしないでください**（`.gitignore` で除外済み）。
- このスクリプトは PoC であり、本番の自動取込処理ではありません。
- `pyzaim` の README では「Zaim の自動連携で取り込まれたカード・銀行データには API ではアクセスできない」と記載されています。  
  このスクリプトで実際に取得できるデータを確認し、期待するデータが含まれているか判断してください。
